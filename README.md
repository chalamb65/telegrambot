# Digi‑Bridge Telegram Bot

👋 Welcome to **Digi‑Bridge** — your bridge to academic success 🚀

This Telegram bot is designed to help students access organized learning resources, proven study strategies, and premium academic support. It provides clear navigation, payment instructions, and interactive buttons for easy use.

---

## ✨ Features
- 📋 **Copyable Payment Details** (CBE, Telebirr, BOA)
- 🌉 **About Us** section
- 📚 **What Is Available?** — resources, notes, solved exams, mock tests
- 📢 **Join Digi‑Bridge** — premium membership instructions
- ❓ **Help** — direct support contact
- 🎯 Clean 2×2 navigation menu for easy access

---

## 📂 Project Structure
- `bot.py` → Main bot script
- Uses **python-telegram-bot v20+** (async API)

---

## ⚙️ Requirements
- Python 3.14+
- `python-telegram-bot` library
